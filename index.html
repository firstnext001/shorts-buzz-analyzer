動画の数値を取得するYouTube APIキーが必要です。バズの理由を文章で解説するAI分析を使う場合はAnthropic APIキーも設定します。

これまでの分析

    バズ分析した動画をお手本に、これから投稿する動画のタイトル・テロップ・概要欄をAIが考えます。

    Anthropic APIキーが必要です

    提案はAI（Claude）が作るため、設定でAnthropic APIキーを登録してください。

    1お手本にするバズ動画

    「バズ分析」で分析した動画から最大5本。AI分析ありの動画ほど参考になります。

    まだ分析した動画がありません。先に「バズ分析」でお手本にしたいショートを分析してください（なしでも提案できます）。

      動画は端末の中で場面を切り出すだけで、動画ファイルそのものは送信しません。

      4動画の狙い・オチ 任意

      1回あたり約20〜50円（Claude）。自動文字起こしを使う場合は1分あたり約1円（OpenAI）が加わります。

      これまでの提案

        設定

        キーの取り方
        1. Google Cloud Console（console.cloud.google.com）でプロジェクトを作成
        2. 「APIとサービス」→「ライブラリ」で YouTube Data API v3 を有効化
        3. 「認証情報」→「認証情報を作成」→「APIキー」
        4. キーの制限で「YouTube Data API v3」のみに限定し、ウェブサイト制限にこのアプリのURLを登録すると安全です

        無料枠は1日10,000ユニット。1回の分析で約5ユニット使います。

        キーの取り方
        1. platform.claude.com にログイン
        2. 「Billing」でクレジットを購入（前払い制）
        3. 「API Keys」→「Create Key」で作成

        AI分析は1回あたり約10〜20円です。コンソールで月の利用上限を設定しておくと安心です。

        キーの取り方
        1. platform.openai.com にログイン
        2. 「Billing」でクレジットを購入（前払い制）
        3. 「API keys」→「Create new secret key」で作成

        「動画に提案」で「自動で文字起こし」を選んだときだけ使います。1分あたり約1円です。

        ジャンル・視聴者・キャラを書いておくと、提案があなたのチャンネル向けになります。

        キーはこのiPhoneの中にだけ保存され、それぞれのサービス（Google・Anthropic・OpenAI）以外には送信されません。
